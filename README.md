## 线路实测：三网回程怎么走，延迟落在哪个区间

这部分基于公开测评里的 traceroute 数据，不是官方宣传话术。

**联通回程最干净。** 洛杉矶直接上 AS4837，经北京、上海、广州的联通节点（219.158.x.x）一路落地，全程不绕路。如果你本机就是联通宽带，这是三个运营商里表现最好的一条。

**电信回程是“借道”。** 洛杉矶先到联通美西 POP（AS10099，118.26.149.9），经香港联通（61.14.201.245）中转，再上 AS4837 到北京，最后交给电信 AS4134、AS23724、AS4812 落地。也就是说电信用户走的不是自己的 163 骨干，而是联通的管子。这正是4837对电信用户也有价值的原因。

**移动回程路径类似。** 同样经联通美西 POP 和香港联通，上 AS4837 到国内，再由移动 AS56040、AS9808、AS56048 落地。去程三家都是各自骨干直连美西，差别不大。

**延迟区间大约 160–215ms。** 具体到节点：上海联通 165ms 上下，北京联通 160–190ms，电信方向 190–200ms，移动方向 175–200ms 且晚高峰有波动。联通最优、电信次之、移动最容易抖，这个排序和线路结构完全对得上。

这里要说清楚一件事：**4837 的优势是晚高峰稳定，不是延迟低。** 160ms 起步的美西机器，和香港、日本 30–70ms 的机器不是一个量级，也不该拿来比。你买它是为了晚上八九点别人掉速的时候你还能跑，不是为了把 ping 压到最低。

硬件层面，母鸡是 E5-2680v4 系列，BBR 已启用，I/O 实测 500–600MB/s，属于这个价位的正常水平。

## 常见问题

**4837 和 9929 到底怎么选？**
延迟敏感、要建站、要稳定优先，选 9929，代价是带宽小、价格高 30%–50%。带宽和流量敏感，比如流媒体、运营、中转，选 4837。两者不是升级关系，是两个方向。

**双ISP住宅IP和普通原生IP差在哪？**
普通原生 IP 只保证归属地在美国，类型仍可能被识别为数据中心。双ISP住宅 IP 的注册信息指向美国本土 ISP，被识别为家宽，对会校验 IP 类型的平台更友好。但两者都不是万能钥匙，具体能不能解，拿到机器实测才算数。

**不限流量是真的不限吗？**
官方标的是“不限月流量”，没有公开的月流量上限数字。实际受带宽和公平使用原则双重约束，长期满载有被干预的可能。真要跑重负载，提前沟通比事后解释好。

**特价年付版能退款吗？**
官方页面标注 48 小时不满意无条件退款，和月付一致；但服务条款里的“大量使用不退”等例外同样适用，且部分产品规则以下单页为准。买之前看一眼条款。

**能装 Windows 吗？**
能，但需要 2G 内存以上，也就是进阶版起。基础版和年付版只有 1G，装上去体验会很差。

**电信用户用4837会不会绕路？**
会绕，但是“有意义的绕”。电信回程经联通美西 POP 和香港联通上 AS4837 回北京，再交给电信落地，路径比联通本网长，但晚高峰的稳定性通常优于电信普通国际线路。
